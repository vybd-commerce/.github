# Vybd

**Build a physical-product brand with your own AI agent. Vybd handles the supply chain.**

Founders work out positioning, research the market and define their products with the agent they already use: Claude, ChatGPT, Codex, Cursor or any MCP client. When the brand is ready, Vybd's operators and partners take over sourcing, compliance, freight and fulfilment.

## Open source

We build in the open. Tools that help you and your agent work with Vybd are released under Apache-2.0. Supplier data, pricing and day-to-day operations stay private.

| Repository | What it is |
|---|---|
| [vybd-agent](https://github.com/vybd-commerce/vybd-agent) | The Vybd app: web chat, remote MCP server any agent can connect to, jobs, and the `vybd` CLI |
| [vybd-brand-builder](https://github.com/vybd-commerce/vybd-brand-builder) | Research service: guided brand brief and evidence-backed research runs |
| [skills](https://github.com/vybd-commerce/skills) | Agent skills for building Shopify Hydrogen storefronts, from an intake folder to a tested deploy on Oxygen |
