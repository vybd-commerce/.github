# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Email **hello@vybd.ai** with the subject line `Security`, or use GitHub's "Report a vulnerability" button on the affected repository where it is enabled. Include:

- the repository and version or commit affected
- what an attacker could do
- steps to reproduce, or a proof of concept

We aim to acknowledge reports within 3 working days and to tell you what we plan to do within 10 working days. Please give us reasonable time to fix the problem before you disclose it publicly.

## Scope

In scope: code in public repositories of this organisation, and Vybd-operated services at `vybd.ai`.

Out of scope: denial-of-service testing, social engineering of Vybd staff or partners, and any testing against data that is not your own.

## Supported versions

We fix security problems on the default branch of each active repository. Archived repositories are not maintained.
